Latest Changelog:

This is Android 16 with October 1st 2025 security patches

10.10.2025:
==============================
- Latest source sync (11.3)
- Integrity is being funky again, due to keybox being banned :(
- Several miscellaneous improvements
- Changed updater to use an overlay instead of my own fork of it (yes, I am quite lazy :P)
- QPR1 is STILL not released, so this build doesn't include full M3E
- This build is quite picky with what kernel you use. For example some versions of ColorX didn't work for me. So I recommend using stock, or having a custom recovery on hand if it bootloops :)

28.09.2025:
==============================

- Various improvements (Including integrity. Should pass by default ;D)
- The Evolver has been improved (yet again)
- And other miscellaneous tweaks

18.09.2025:
==============================

- The Evolver has been improved
- And other miscellaneous tweaks

Notes:
==============================
- LineageOS-based source. Signed build.
- Always dirty flash at your own risk. If your device bootloops, revert to an older build that boots.
- Stock kernel
- If rooted, check your modules, because they tend to spoof secpatch
